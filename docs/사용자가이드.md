# 사용자 가이드

"기술지원 답변 도우미"는 고객 기술지원 메일을 읽고 **회신 초안**을 만들어 주는 Outlook 애드인입니다. 메일을 자동으로 보내지 않습니다. 만들어진 초안은 반드시 직접 검토한 뒤 [보내기]를 눌러 발송합니다.

> **개인정보 주의**: 답변을 만들 때 고객 메일 본문과 텍스트 첨부 파일의 발췌 내용이 **선택한 LLM 공급자(Anthropic, OpenAI, xAI 등)에게 전송**됩니다. 회사 정책상 외부로 보내면 안 되는 내용이 있는 메일에는 사용하지 마세요. 지식 문서(매뉴얼·과거 답변)는 내 PC에서 임베딩해 검색하며, 검색으로 고른 발췌문만 메일 내용과 함께 전송됩니다.

---

## 1. 처음 실행하기: LLM 프로필과 API 키

답변은 LLM 프로필(공급자 + 모델 + API 키)을 골라 생성합니다.

### 환경 변수가 있는 경우(자동)

처음 실행할 때 프로필이 하나도 없고 다음 환경 변수에 값이 있으면 프로필이 자동으로 만들어집니다. 키 자체는 설정 파일에 저장되지 않고 환경 변수에서 읽습니다.

| 환경 변수 | 만들어지는 프로필 | 기본 모델 |
|---|---|---|
| `ANTHROPIC_API_KEY` | Claude | `claude-opus-5` |
| `OPENAI_API_KEY` | OpenAI | `gpt-5.1` |
| `XAI_API_KEY` | xAI Grok (Base URL `https://api.x.ai/v1`) | `grok-4` |

- 환경 변수는 Outlook 프로세스 → 사용자 → 시스템 순서로 읽으므로, Outlook이 켜진 뒤에 추가한 변수도 인식됩니다.
- **Anthropic 키가 워크스페이스에 속하지 않은 키**라면 Workspace ID(`wrkspc_…`)가 필요합니다. 프로필이 처음 만들어질 때 환경 변수 `ANTHROPIC_WORKSPACE_ID`의 값이 사용됩니다. 이미 프로필이 만들어진 뒤에는 [설정]에서 직접 입력합니다.

### 설정에서 직접 등록하는 경우

1. Outlook [홈] 탭 → "기술지원" 그룹 → **[설정]** (또는 작업창의 "설정…" 링크)을 엽니다.
2. **LLM 프로필** 탭에서 [Claude 추가], [OpenAI 추가], [xAI 추가] 중 하나를 누릅니다.
3. 오른쪽 입력 칸을 채웁니다.
   - **표시명**: 목록에 보일 이름
   - **공급자**: Anthropic (Claude) / OpenAI 호환 (OpenAI·xAI 등)
   - **모델**: 모델 ID(아래 "모델 고르기" 참고)
   - **Base URL**: 비워 두면 공급자 기본값. xAI는 `https://api.x.ai/v1`
   - **최대 토큰**, **Effort**(low / medium / high / max, Anthropic 전용)
   - **API 키**: "직접 입력(DPAPI 암호화 저장)"을 고르고 키를 붙여 넣거나, "환경 변수에서 읽기"를 고르고 **변수 이름**(예: `ANTHROPIC_API_KEY`)을 입력합니다. 직접 입력한 키는 내 Windows 계정으로만 풀 수 있게 암호화되어 `%APPDATA%\TechSupportReply\secrets.dat`에 저장됩니다.
   - **Workspace ID**: 워크스페이스에 속하지 않은 Anthropic 키만 필요합니다(`wrkspc_…`).
4. **[연결 테스트]**를 눌러 키와 모델이 정상인지 확인합니다. 성공하면 녹색, 실패하면 빨간색으로 원인이 표시됩니다.
5. 아래쪽 **기본 답변 프로필**과 **제품 분류 프로필**을 고릅니다(제품 분류에는 저렴하고 빠른 모델이 좋습니다).
6. **지식 폴더** 탭의 **RAG 루트**에 관리자가 알려 준 공유 폴더(예: `\server\KB`)를 입력하거나 [찾아보기…]로 고릅니다. [지금 동기화]로 색인을 미리 받아 둘 수 있고, 제품별 색인 버전과 빌드 시각이 표에 표시됩니다.
7. **사용자** 탭의 이름·직함·회사·기본 어조는 답변 서명과 어조에 사용됩니다.
8. **[저장]**을 누릅니다.

### 모델 고르기

프로필의 **[모델 목록 불러오기]**를 누르면 그 프로필의 키로 쓸 수 있는 모델을 공급자에게서 받아 **모델** 드롭다운에 채웁니다.

- Claude는 적응형 사고를 지원하는 모델만, OpenAI·xAI는 대화형 모델만 보입니다(임베딩·음성·이미지·비디오·실시간 등 대화용이 아닌 모델은 제외). OpenAI·xAI 목록은 최신 모델이 먼저 보입니다.
- 목록에 없는 모델 ID도 **직접 입력**할 수 있습니다. 현재 입력된 값은 목록을 불러와도 지워지지 않습니다.
- 키가 없으면 "API 키가 없습니다. 키를 입력하거나 환경 변수를 확인하세요."가 표시됩니다.
- Workspace 오류가 나면 Workspace ID를 입력한 뒤 다시 시도합니다.
- 모델을 고른 뒤 **[저장]**을 누르세요.

## 2. 사용 흐름

1. Outlook에서 답변할 **메일을 선택**합니다(또는 메일을 열어 둡니다).
2. [홈] 탭 "기술지원" 그룹의 **[기술지원 답변]**을 누릅니다. 오른쪽에 작업창이 열리고, 애드인이 제품군을 판별합니다(키워드 + LLM).
3. **제품군**을 확인합니다. 판별 결과와 신뢰도·근거가 제품군 아래에 표시됩니다(예: `LS-DYNA · 신뢰도 0.92 · LLM — …`). 틀렸다면 드롭다운에서 직접 바꿉니다. **바꾼 제품으로 검색·생성**합니다.
4. **LLM 프로필**을 확인합니다(아래 "LLM 프로필 드롭다운" 참고). 필요하면 **추가 지시**(예: "라이선스 로그를 요청해 주세요")를 입력하고, "지식 폴더(RAG) 검색 사용"을 켜거나 끕니다.
5. **[답변 생성]**을 누릅니다. 답변이 미리보기 창에 실시간으로 나타납니다. 잘못 눌렀으면 **[중지]**를 누릅니다.
6. 미리보기 내용을 **읽고 직접 수정**합니다(이 칸은 편집할 수 있습니다). 고객에게 나가는 글이므로 사실 관계와 표현을 꼭 확인하세요.
7. **[회신 초안 만들기]**를 누르면 "전체 회신" 초안 창이 열리고 작성한 답변이 맨 위에 들어갑니다. 기존 서명과 인용된 메일 이력은 그대로 유지됩니다.
8. 초안 창에서 최종 검토한 뒤 **직접 [보내기]**를 누릅니다. 애드인은 절대 자동으로 보내지 않습니다.

### LLM 프로필 드롭다운

- **API 키가 등록된 프로필만** "표시명 · 모델"(예: `Claude · claude-opus-5`) 형태로 나타납니다.
- 마지막으로 고른 프로필을 기억합니다. 처음에는 기본 답변 프로필이 선택됩니다.
- 키가 등록된 프로필이 하나도 없으면 "API 키가 등록된 LLM 프로필이 없습니다. [설정] → LLM 프로필에서 키를 입력하거나 환경 변수를 설정한 뒤 다시 시도하세요."라고 안내되고 **[답변 생성] 버튼이 꺼집니다**.
- [설정]에서 키를 입력하고 **[저장]**하면 열려 있는 작업창의 목록이 바로 갱신되고 안내가 사라집니다.

### 참고 문서와 경고 읽는 법

- **참고 문서**: 답변의 근거로 사용한 문서 목록입니다(파일명과 페이지). 목록은 작업창에만 표시되고 메일 본문에는 들어가지 않습니다. 근거를 직접 열어 확인하세요.
- **주황색 경고(⚠)**: 예) 지식 폴더(RAG 루트)가 설정되지 않아 RAG 없이 생성, 색인이 없거나 동기화에 실패, 공유 폴더의 products.json을 읽지 못함, 제품 지침을 읽지 못해 공통 지침만 사용 등. 이 경우 답변이 문서 근거 없이 일반 지식으로 만들어졌을 수 있으니 더 주의해서 검토하세요.
- **`[확인 필요]`**: AI가 확신하지 못하거나 근거 문서에서 확인하지 못한 문장 끝에 붙는 표시입니다. **고객에게 보내기 전에 반드시 사실을 확인하고 이 표시를 지우거나 고치세요.**
- 상태줄(맨 아래)에는 진행 상황과 오류가 한국어로 표시됩니다(오류는 빨간색).

## 3. 자주 묻는 질문

**Q. "API 키가 올바르지 않거나 등록되지 않았습니다"라고 나옵니다.**
[설정] → LLM 프로필에서 키를 다시 입력하고 [연결 테스트]로 확인하세요. "환경 변수에서 읽기"를 쓰는 경우 변수 이름이 맞는지, 변수에 값이 있는지 확인합니다. 환경 변수를 새로 추가했다면 Outlook을 다시 시작해 보세요.

**Q. "API 키는 워크스페이스에 속해 있지 않아 Workspace ID가 필요합니다"라고 나옵니다.**
Anthropic 키가 워크스페이스에 속하지 않은 경우입니다. [설정] → LLM 프로필의 **Workspace ID**에 `wrkspc_`로 시작하는 ID를 입력하고 [저장]하세요. 또는 워크스페이스에 속한 키를 사용합니다.

**Q. "모델 이름을 찾을 수 없습니다"라고 나옵니다.**
프로필의 모델 ID를 확인하세요. [모델 목록 불러오기]로 쓸 수 있는 모델을 확인할 수 있습니다.

**Q. "요청 한도를 초과했습니다" 또는 "일시적인 오류가 발생했습니다"라고 나옵니다.**
잠시 후 다시 시도하세요.

**Q. 공유 폴더가 오프라인(회사 네트워크 밖)입니다.**
마지막으로 동기화한 로컬 캐시(`%LOCALAPPDATA%\TechSupportReply\cache`)의 색인으로 계속 검색합니다. 캐시가 전혀 없으면 경고와 함께 RAG 없이 생성합니다. 네트워크에 연결되면 다음 사용 때 자동으로 동기화되며, [설정] → 지식 폴더의 [지금 동기화]로 바로 받을 수도 있습니다.

**Q. 제품군을 잘못 판별했습니다.**
작업창의 제품군 드롭다운에서 직접 고르면 그 제품 기준으로 검색·생성합니다.

**Q. 기술지원 그룹(리본)이 보이지 않습니다.**
설치가이드.md의 "Outlook에서 활성화 확인"과 "문제 해결"을 참고하세요.

**Q. 문제가 생겼는데 원인을 알고 싶습니다.**
로그를 확인하세요: `%LOCALAPPDATA%\TechSupportReply\logs\yyyy-MM-dd.log`. 메일 본문과 API 키는 기록되지 않으므로 관리자에게 로그 파일을 전달해도 됩니다. 설정은 `%APPDATA%\TechSupportReply\settings.json`에 저장됩니다.
